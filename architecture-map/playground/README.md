# architecture-map playground

A runnable map of this skill, so the city and the flows sequence can be opened
without installing the skill into another repo.

```bash
cd architecture-map/playground
npm install
npm test
npm run dev
```

Then open http://localhost:5173.

The city is what you get on load. Each flow in the left rail is its own
sequence map — participants across, time down, the same packets.
